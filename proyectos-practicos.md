# Proyectos prácticos

Durante este aprendizaje, las prácticas y proyectos reales se desarrollarán en repositorios separados.

Esto permitirá:

- Mantener organizado el contenido teórico
- Separar documentación y proyectos reales
- Trabajar aplicaciones Flask de manera profesional
- Llevar control independiente de cada proyecto

El primer proyecto práctico será un formulario web para recopilación de requerimientos de clientes.
