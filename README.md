# Learning Flask


Repositorio dedicado al aprendizaje de Flask desde cero.

## Objetivos

- Comprender cómo funciona Flask
- Aprender desarrollo backend web con Python
- Entender rutas, templates, formularios y estructura de proyectos
- Preparar las bases para proyectos más grandes
- Construir aplicaciones reales usando Flask y PostgreSQL
